System Architecture & Data Flow

Understanding how data flows between the frontend components and the backend Next.js API routes.

1
Transcript Sync & Audio Playback Flow

Frontend Audio Controller

  • Tracks the currentTime of the audio player.
  • Compares it to the current sentence's start and end timestamps in the JSON.
  • Triggers a visual highlight and automatic scroll to the active transcript line.

User Interactivity

  • Click Sentence: Triggers player seek to start timestamp.
  • Loop Mode: When active, audio player loops between start and end of the selected sentence.
↓
2
Shadowing & Recording Flow

Microphone Recording (Web Audio)

  • Uses MediaRecorder API to capture voice from user microphone.
  • Saves the audio chunks in memory as a Blob URL.
  • Allows the user to play back their recorded voice immediately side-by-side with the podcast audio.

Self-Evaluation & Scoring

  • Allows simple self-check (listening side-by-side).
  • Simulates a pronunciation scoring system (visual chart) comparing speaking speed and patterns.
↓
3
AI Discussion Chat API Flow

Frontend Payload

Sends request to /api/chat containing:

  • User input message.
  • Selected persona (Angela/Mike/Tutor).
  • Context: Episode ID, Active Sentence (so the AI knows what specific line the user is studying).

Next.js API Route (Backend)

  • Receives payload securely on the server.
  • Loads system prompt for the selected persona.
  • Provides a smart, mock response engine by default (making the app runnable without API keys), with simple support for environment keys (e.g. Gemini API) if configured.
